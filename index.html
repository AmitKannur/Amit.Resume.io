Featured Projects

Major Project • 2026–2027

Cybersecurity Using Generative AI: Adversarial Attack Detection & Automated Response

B.L.D.E.A's V.P. Dr. P.G. Halakatti College of Engineering | Guide: Mr. Santosh Kumar S Dewar

Engineered a multi-layered AI-powered network intrusion detection and automated response framework trained on the CICIDS 2017 benchmark dataset to detect known and zero-day attacks while hardening defenses against adversarial perturbations.

  • Hybrid Detection Pipeline: Built a hybrid detection pipeline combining Random Forest, Autoencoder anomaly detection, and LSTM sequence modeling, achieving 96.5% detection accuracy and reducing false positives by 72%.
  • Generative Simulation & RAG Intelligence: Integrated Generative Adversarial Networks (GANs) and FGSM perturbation testing for synthetic attack simulation, alongside Retrieval-Augmented Generation (RAG) with NVD CVE threat intelligence for automated mitigation and IP blocking in under 66 ms.
  • Modular Architecture & Live Dashboard: Developed a modular Python architecture and real-time security monitoring dashboard to track live network packets, alert severity, and automated countermeasures.
